# Purpose

This document defines the performance requirements of WorkbookTemplate.xlsm.

The software shall remain responsive while processing large TXT files generated by testing machines.

---

# Design Philosophy

Performance shall always have priority over visual effects.

Engineering accuracy shall never be sacrificed for speed.
