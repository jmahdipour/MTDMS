# Purpose

The Graph Style Engine defines the visual appearance of all engineering charts generated by MTDMS.

Its responsibility is limited to presentation.

Engineering data and calculated values are never modified by this engine.

---

# Objectives

The Graph Style Engine shall

• Apply consistent chart formatting

• Support multiple visual themes

• Ensure publication-quality appearance

• Separate engineering data from presentation

• Allow administrator customization

---

# Engineering Philosophy

Engineering Data

Changing the chart style shall never change the engineering values.
