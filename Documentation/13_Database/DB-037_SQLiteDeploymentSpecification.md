# Purpose

This document defines how the MTDMS SQLite database shall be deployed, organized, backed up, and maintained within an Excel 2019 environment.

The deployment architecture is designed specifically for an Excel-based application that imports engineering data from TXT files.

---

# Objectives

The deployment architecture shall

• Be simple

• Require no installation server

• Operate completely offline

• Support ISO/IEC 17025 traceability

• Support backup and archive
