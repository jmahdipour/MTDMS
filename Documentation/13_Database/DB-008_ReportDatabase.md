# Purpose

The Report Database stores administrative information about every report generated by MTDMS.

It is the central reference table connecting imported TXT files, calculated engineering results, validation status, reports and archive records.

The table does not store raw engineering data.

The TXT file remains the master engineering record.

---

# Objectives

The Report Database shall

• Register every report

• Link reports to imported TXT files

• Link reports to certificates

• Link reports to customers

• Link reports to standards

• Support complete traceability
