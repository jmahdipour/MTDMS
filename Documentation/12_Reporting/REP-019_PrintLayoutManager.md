# Purpose

The Print Layout Manager controls the visual arrangement of every printed report generated by MTDMS.

It defines how information is positioned on the page.

It never changes engineering values.

It never modifies calculations.

---

# Design Philosophy

Engineering calculations

↓

Engineering Report

↓

Print Layout

↓

Printed Document

Presentation is independent of engineering data.
