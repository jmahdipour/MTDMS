# TXT Error Codes Specification

Document ID : MTDMS-IMP-007

Version : 0.1.0

Platform

Microsoft Excel 2019

Language

VBA

Input

TXT Files Only

---

# Purpose

This document defines every TXT import error generated by MTDMS.

Every error shall have

• Unique Error Code

• Description

• Severity

• Recommended Action

• Log Entry

• Recovery Method

# Severity Levels

INFO

Operation completed successfully.

WARNING

Operation continued.

Operator attention required.

ERROR

Import stopped.

Recovery possible.

CRITICAL

Application integrity at risk.

Immediate stop.

---

# Error Code Format

```
IMP-XXXX
```

Example

```
IMP-0001
```
