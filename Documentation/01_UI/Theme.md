# Theme Specification

Document ID : MTDMS-UI-002

Version : 0.1.0

Platform

Microsoft Excel 2019

Ribbon XML

VBA

---

# 1. Purpose

This document defines the visual identity of MTDMS.

All worksheets, Ribbon elements, charts, tables and reports must follow this theme.

No custom colors may be introduced without approval.

# 14. Dark Mode

Not supported in v1.0.

The theme is optimized for laboratory environments and printed reports.

---

# 15. Consistency Rules

- Use only approved colors.
- Use only Segoe UI.
- Do not use gradients.
- Do not use shadows excessively.
- Do not use bright colors.
- Keep high contrast for readability.
- Charts and reports must use the same palette.
