# Purpose

This document defines all typography rules used in MTDMS.

Uniform typography increases readability, reduces operator fatigue and creates a professional industrial appearance.

---

# Design Philosophy

Typography shall be

• Clean

• Professional

• Industrial

• Consistent

• Readable

No decorative fonts shall be used.
