# Icon Specification

Document ID : MTDMS-UI-005

Version : 0.1.0

Platform

Microsoft Excel 2019

Ribbon XML

---

# Purpose

This document defines the icon library used throughout MTDMS.

Icons shall provide quick visual identification of commands.

Icons are decorative only and shall never replace text labels.

---

# General Rules

✔ Every Ribbon button shall have an icon.

✔ Every icon shall have a text caption.

✔ Icons shall remain consistent throughout the application.

✔ Icons shall follow Microsoft Office Fluent Design.
