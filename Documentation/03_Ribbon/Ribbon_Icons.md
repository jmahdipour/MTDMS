# Ribbon Icon Specification

Document ID : MTDMS-RBN-006

Version : 0.1.0

Platform

Microsoft Excel 2019

Ribbon XML

Workbook

---

# Purpose

This document standardizes every Ribbon icon used by MTDMS.

Icons shall be

• Consistent

• Professional

• Industrial

• Recognizable

Icons shall never replace captions.

# Design Rules

✔ Every Ribbon button shall have an icon.

✔ Every icon shall have a text label.

✔ Icons shall remain consistent throughout the application.

✔ Engineering icons shall follow ISO terminology.

✔ Custom icons shall use transparent PNG format.
