# TB-032 — ISO 6892-1 Final Result Release Package, Report Output & Export Contract Specification

**Status:** Approved / Frozen  
**Parent:** TB-031  
**Scope:** Exported TXT-file tensile-test analysis only  
**Platform:** Excel 2019 VBA Add-in  
**UI:** Excel Ribbon — English / LTR

## 1. Purpose

Defines the final output contract after Import, Normalization, Event Detection, ISO 6892-1 Analysis, Operator Review/Override, Recalculation, Validation and Release Gate.

**Core rule:** The Final Output is the released analytical result package, not raw data and not an independently recalculated report.

## 2. Output Layers

```text
RAW
CALCULATED
PRESENTATION
```

Raw TXT data is immutable. Calculated Results are generated by the Analysis Engine. Presentation data may contain graph correction but must never overwrite Raw data.

```text

BlockingIssues = 0
BlockingConflicts = 0
Provenance = COMPLETE
ReleaseGate = OPEN
```

## 22. Released Package Immutability

After Release, Raw Dataset, Final Results, Events, Validation, Audit, Provenance and Release Decision are immutable.

Post-release changes require:

```text
New Review Session
→ New Package Version
→ Recalculation
→ Validation
→ New Release Snapshot
```

Previous versions are retained.

## 35. Missing Values

Missing values must not be fabricated as 0, -1, 9999 or another numeric placeholder.

Permitted representation is defined by the active Export Contract, for example:

```text
NOT_AVAILABLE
```

or an empty CSV field where specified.

## 36. Unit Contract

All numeric Results in machine-readable output have explicit Units. Example:

```text
Stress = MPa
Force = N
Length = mm
Strain = %
YoungModulus = GPa
```

## 37. Decimal and Rounding Contract

Internal calculation precision is retained. Display rounding does not feed back into calculations.

Example:

```text
CalculatedValue = 523.736492 MPa
DisplayedValue  = 523.7 MPa
```

## 38. Single Source of Truth

```text
Analysis Engine
      ↓
Result Package
   ↙     ↓      ↘
Report   CSV   Dataset Export
```

Report and Export generators consume the Result Package and do not independently recalculate Rp0.2, Rm, Young's Modulus, A% or other Results.

## 43. Export Regeneration

Formatting-only changes do not require analytical recalculation. Changes affecting Results require recalculation and validation before a new Release.

## 44. Output Consistency

The following must agree:

```text
Result Package
Excel Report
Machine-readable Export
```

Any disagreement creates:

```text
OUTPUT_INCONSISTENCY
```

and blocks Released Output.
