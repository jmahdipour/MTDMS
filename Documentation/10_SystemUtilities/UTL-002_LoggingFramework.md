# Purpose

The Logging Framework records operational events generated by MTDMS during normal operation.

Unlike the Audit Manager, which records user activities for traceability, the Logging Framework records technical events used for diagnostics, troubleshooting and software maintenance.

Engineering calculations shall never depend on log files.
